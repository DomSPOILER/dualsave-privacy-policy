C.CONJUNTOS DE DADOS QUE COLETAMOS E PARA QUAL FINALIDADE:

Aqui você encontra informações sobre as finalidades para as quais processamos seus dados pessoais, bem como nossa base legal para o processamento, a definição de dados “pessoais” e “não pessoais” e como eles são processados ​​tecnicamente.

Dados não pessoais

Durante sua interação com nosso site e Serviços, podemos coletar informações agregadas, não pessoais e não identificáveis, que podem ser disponibilizadas ou coletadas por meio do seu acesso e uso dos Serviços (“ Dados Não Pessoais ”). Não temos conhecimento da identidade do usuário de quem os Dados Não Pessoais são coletados. Os Dados Não Pessoais coletados podem incluir informações agregadas sobre seu uso e informações técnicas transmitidas pelo seu dispositivo, como: o tipo de navegador ou dispositivo que você usa, sua preferência de idioma, data e hora, localização do país, etc.

Dados pessoais

Também podemos coletar de você, direta ou indiretamente, durante seu acesso ou interação com o site ou os Serviços, informações de identificação pessoal, ou seja, informações que identificam um indivíduo ou que podem, com um esforço razoável, ser usadas para identificar um indivíduo (“ Dados Pessoais ”). Os tipos de Dados Pessoais que coletamos, bem como a finalidade do processamento e a legalidade, estão especificados na tabela abaixo.

Não coletamos nem processamos, de forma consciente, quaisquer Dados Pessoais que constituam ou revelem origem racial ou étnica, opiniões políticas, crenças religiosas ou filosóficas, filiação sindical, dados genéticos, dados biométricos, dados relativos à saúde de uma pessoa ou dados relativos à vida sexual ou orientação sexual de uma pessoa (“ Categorias Especiais de Dados Pessoais ”).
