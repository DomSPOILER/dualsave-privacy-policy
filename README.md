# DualSave — Política de Privacidade

Página estática da Política de Privacidade do DualSave, pronta para publicação no GitHub Pages.

## Publicação

1. Crie um repositório público no GitHub.
2. Envie `index.html` para a raiz do repositório.
3. Em **Settings → Pages**, selecione a branch principal e a pasta `/ (root)`.
